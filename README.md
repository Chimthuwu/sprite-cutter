## What it does

- Slice sprite sheets (tile size or rows/columns)
- Preview with live grid overlay
- Drag & reorder animation frames
- Export GIF or PNG sequence

---

## Why

Most sprite tools are slow, clunky, or require uploads.

SpriteCut runs entirely in your browser — fast and private.

---

## Tech

- React + Vite  
- Tailwind  
- Zustand  
- dnd-kit  
- Canvas API  
- gif.js  

---

## Run locally

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
cd YOUR_REPO
npm install
npm run dev
```
